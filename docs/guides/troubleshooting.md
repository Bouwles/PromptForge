# Troubleshooting

Common fixes:

- No models: start Ollama and pull at least one model.
- Browser cannot connect: use Chrome or Edge and configure `OLLAMA_ORIGINS`.
- Folder scan fails in web mode: reselect the folder and grant permission.
- Generated prompt is too broad: add project memory, important systems, and selected files.
- Prompt is too long: use Make Shorter after generation.
