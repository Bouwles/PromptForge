# Prompt Refinement Guide

Refinement actions are for changing the prompt, not changing the user's request.

- Make Shorter removes redundancy.
- Make More Detailed adds edge cases and implementation notes.
- Make More Specific turns vague wording into testable requirements.
- Add Tests adds checkable acceptance coverage.
- Split Into Prompts breaks large work into standalone steps.

Use Save only after the output is ready to reuse.
