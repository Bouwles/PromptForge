# Product Story

PromptForge is built for the moment before a coding agent starts work. That moment is usually messy: a feature idea, a bug complaint, a half-remembered constraint, and a fear that an existing system will break.

The app makes that moment explicit. It collects the raw request, project memory, restrictions, selected files, and stack summary, then turns them into a structured prompt with goals, non-regression rules, implementation notes, and test expectations.

The showcase value is the full loop: local generation, project scanning, editing, refinement, persistence, and history.
