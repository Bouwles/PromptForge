# Release Checklist

Before cutting a PromptForge release:

- Run `npm test`.
- Run `npm run build`.
- Confirm the README images render on GitHub.
- Confirm Settings can test the configured backend.
- Generate one one-off prompt.
- Generate one project-aware prompt with pinned files.
- Save, favorite, duplicate, edit, and delete a prompt from History.
- Build desktop installers on the target platform.
- Tag the release and attach the installer or packaged zip.
