# Demo Script

Use this sequence when recording PromptForge for a portfolio, README GIF, or recruiter walkthrough.

1. Open Settings and show the Ollama connection test.
2. Create a project and connect a real local repo.
3. Let the scanner detect framework, language, routes, tests, and config.
4. Pin one important file and select one supporting file.
5. Paste a rough request with typos and missing structure.
6. Generate a prompt for Claude Code.
7. Use Add Tests, Make More Specific, and Split Into Prompts.
8. Save the final prompt and show it in History.

The best demo angle is not "AI writes text." It is "the app turns chaos into a disciplined engineering handoff."
