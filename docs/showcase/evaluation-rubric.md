# Evaluation Rubric

Use this rubric to judge whether PromptForge is showcase-ready.

- First impression: README shows the product visually within the first screen.
- Setup: a new developer can install, run, test, and build without guessing.
- Functionality: one-off prompts, project prompts, scanning, refinement, saving, and history all work.
- Trust: privacy boundaries and runtime differences are explained clearly.
- Engineering: tests cover core behavior and the app has a maintainable separation between desktop, web, and renderer.
- Demo quality: the project has screenshots, workflow media, and a repeatable demo script.
