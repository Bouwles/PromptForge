# README Media Plan

The README should make the app legible without requiring a local install.

- Hero image: one full-product screenshot or illustration showing the app shell.
- Workflow image: request, scan, generate, refine, save.
- Demo GIF: short loop showing the app moving from raw request to saved prompt.
- Optional release image: installer/download section once binaries are attached.

Keep media in `docs/assets/` so README links work on GitHub and inside local clones.
